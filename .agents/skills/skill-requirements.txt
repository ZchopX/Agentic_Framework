Only skills with additional downloadable requirements are listed here.
Skills without extra package/tool requirements are intentionally omitted.

docx
- pandoc: extract/read .docx content
- npm package `docx`: create new .docx files (`npm install -g docx`)
- LibreOffice (`soffice`): convert .doc/.docx and export PDFs
- Poppler (`pdftoppm`): convert rendered PDFs to images for review

pptx
- Python package `markitdown[pptx]`: extract/read presentation text
- Python package `Pillow`: generate thumbnail grids
- npm package `pptxgenjs`: create presentations from scratch (`npm install -g pptxgenjs`)
- LibreOffice (`soffice`): convert .pptx to PDF for QA
- Poppler (`pdftoppm`): convert presentation PDFs to slide images

pdf
- Python package `pypdf`: merge, split, rotate, watermark, encrypt, and fill forms
- Python package `pdfplumber`: extract text and tables
- Python package `reportlab`: create PDFs
- Python package `pandas`: write extracted tables to spreadsheet-friendly outputs
- CLI tool `qpdf`: command-line PDF manipulation and repair
- Poppler tools (`pdftotext`, `pdfimages`): text and image extraction
- Optional OCR: Python packages `pytesseract` and `pdf2image`, plus Tesseract OCR

Suggested installs for this repo
- docx skill: install `pandoc`, `LibreOffice`, `poppler`, and `npm install -g docx`
- pptx skill: `pip install "markitdown[pptx]" Pillow`, install `LibreOffice` and `poppler`, then `npm install -g pptxgenjs`
- pdf skill: prefer `conda install pypdf reportlab pandas qpdf poppler`, then `pip install pdfplumber pypdfium2`; for OCR add `pip install pytesseract pdf2image` and install Tesseract
