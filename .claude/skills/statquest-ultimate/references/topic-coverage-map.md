# Topic Coverage Map

Use these prompts to decide what must be included for each concept family.

## Statistics

Always cover:
- what is being measured
- what the quantity means in plain English
- a hand-sized numerical example
- the most common misinterpretation

Useful extras:
- sampling intuition
- population vs sample distinction
- uncertainty language

## Probability

Always cover:
- event or random variable in words
- what the probability is attached to
- a tiny table, count, or repeated-trials story
- why probabilities are between 0 and 1

Useful extras:
- conditional probability
- base-rate trap
- expected value intuition

## Hypothesis testing and intervals

Always cover:
- what question the method is answering
- what is fixed vs what varies
- what the result does not mean
- one example with a concrete threshold or range

Useful extras:
- p-value vs confidence interval vs credible interval
- statistical significance vs practical importance

## Regression and machine learning

Always cover:
- what is being predicted or explained
- what counts as an input and output
- how the model learns or fits
- what a parameter is doing intuitively

Useful extras:
- overfitting
- regularization
- train/test split
- bias-variance tradeoff

## Bayesian methods

Always cover:
- prior as starting belief
- likelihood as evidence from data
- posterior as updated belief
- one small update example

Useful extras:
- shrinkage intuition
- why Bayesian estimates can be more stable in small samples
- credible interval interpretation

## Time series and econometrics

Always cover:
- what changes over time
- why temporal order matters
- what the model uses from the past
- one tiny sequential example

Useful extras:
- autocorrelation
- lag choice
- stationarity
- structural shocks
- impulse response intuition
- BVAR shrinkage as "pulling wild estimates toward something calmer"

## Coding and algorithms

Always cover:
- what problem the algorithm solves
- input, output, and main loop
- one tiny trace through the steps
- time or memory cost only if relevant

Useful extras:
- why a naive idea fails
- tradeoffs against alternatives
